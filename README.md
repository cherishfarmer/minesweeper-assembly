# 💣 Minesweeper in Assembly (EASy68K)

## 🌱 About
A classic **Minesweeper** game implemented entirely in **Motorola 68000 Assembly** using the **EASy68K simulator**. This project was built to explore low-level programming concepts such as memory management, branching, and input handling, while recreating a nostlagic, early 2000s-themed puzzle game from scratch.

## 🕹️ How to Play

1. **Download EASy68K**  
   🔗 [http://www.easy68k.com/](http://www.easy68k.com/)

2. **Open the game file**  
   - Launch EASy68K.  
   - Go to **File → Open**, and select the `.S68` (S-Record) file from this repository.  

3. **Run the program**  
   - Click **“Play”** ▶️ on the debugger toolbar to start the game.  
   - Follow the on-screen prompts to reveal tiles and avoid mines!
